# IOS_CW2_Supportives

This is an iOS application project.

## Getting Started

1. Open `IOS_CW2_Supportives.xcodeproj` in Xcode.
2. Build and run the project using `Cmd + R` or the run button in the toolbar.

## Project Structure

* `IOS_CW2_Supportives/`: Contains the main source code and resources for the app.
* `IOS_CW2_SupportivesTests/`: Contains unit tests for the application.
* `IOS_CW2_SupportivesUITests/`: Contains UI tests for the application.
* `IOS_CW2_Supportives.xcodeproj`: The Xcode project file.
